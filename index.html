Hospital Intake Chatbot

A learning project: a text chatbot that acts like a hospital front-desk intake assistant. It asks about symptoms, vitals, and medical history, gives a general triage suggestion, and can book an appointment with a reference number.

Demo only. This is not medical advice and not a real hospital system. Do not enter real personal or medical information.

Features

  • Symptom collection and follow-up questions
  • Vitals and medical history capture
  • Emergency keyword detection
  • Appointment booking with a reference number

Run it locally

git clone https://github.com/YOUR-USERNAME/hospital-chatbot.git
cd hospital-chatbot/hospital\ chatbot
pip install -r requirements.txt
export GEMINI_API_KEY="your-key-here"
python app.py

Then open http://127.0.0.1:5000 in your browser.

Source code is in the hospital chatbot folder of this repository.
